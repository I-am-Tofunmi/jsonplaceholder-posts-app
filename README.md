# Blog Posts App

A single-page web app that fetches and displays posts from the JSONPlaceholder API, with search filtering and loading, error and empty states.

## 🔗 Live Demo


## ✨ Features
- Fetches 100 posts from JSONPlaceholder API
- Search/filter posts by title in real time
- Loading state while data is being fetched
- Error state if fetch fails
- Empty state if search matches nothing
- Fully responsive design

## 🛠️ How to Run Locally
1. Clone the repo
   git clone https://github.com/I-am-Tofunmi/jsonplaceholder-posts-app.git
2. Open index.html with Live Server in VSCode
